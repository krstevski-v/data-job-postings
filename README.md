## Project description
Data cleaning and EDA of 674 data-related US jobs posted on Glassdoor.

## Tools used
Python - pandas, seaborn, matplotlib

## Overview
The original dataset contains 674 unique job postings with the following attributes: Job Title, Salary Estimate, Job Description, Rating, Company Name, Location, Headquarters, Company Size, Year of Founding, Type of Ownership, Industry, Sector, Revenue and Competitors.

The project features data cleaning, standardization of attributes, job-role classification, location parsing and extraction of required technical skills. The output is a cleaned .csv containing only analytically relevant, standardized attributes which are later used to answer 4 questions:
  1. How do advertised salary bounds differ by role?
  2. Which industries offer the highest median salary?
  3. Which technical skills are most in demand?
  4. How does skill demand vary between different data roles?
